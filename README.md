# BilleteraVirtual

Un proyecto de aplicación móvil diseñado para la gestión de finanzas personales, permitiendo la compra y venta de dólares, así como un registro detallado de movimientos financieros.

## 📝 Descripción

**BilleteraVirtual** es una aplicación desarrollada para Android que simula las operaciones esenciales de una billetera digital. Su objetivo principal es ofrecer una interfaz intuitiva y un flujo eficiente para el control de ingresos, egresos y transacciones de cambio de divisa.

### Características Principales:
* **Compra y Venta de Dólares:** Módulo para simular transacciones de cambio de divisas con cálculo en tiempo real.
* **Registro de Movimientos:** Historial detallado de todas las transacciones realizadas (depósitos, retiros, compras y ventas).
* **Gestión de Saldo:** Visualización en tiempo real del saldo disponible en las diferentes monedas.

## 🛠️ Tecnologías y Estructura del Proyecto

El proyecto está configurado con las siguientes herramientas de desarrollo:

* **Lenguaje:** Kotlin / Java (Estructura nativa de Android).
* **Sistema de Construcción:** Gradle con Kotlin DSL (`.gradle.kts`).
* **Arquitectura:** MVVM (Model-View-ViewModel) para garantizar la separación de conceptos, escalabilidad y facilidad de pruebas.

### Estructura de Archivos Principal:
* `/aplicación`: Contiene el código fuente del proyecto, recursos visuales (`res`), interfaces de usuario y la lógica de negocio.
* `build.gradle.kts`: Configuración de dependencias y plugins a nivel de proyecto y aplicación mediante Kotlin DSL.
* `settings.gradle.kts`: Declaración y definición de los módulos del proyecto.
